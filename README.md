# Yumitask — Telegram Mini App (биржа заданий)

Рабочее название проекта: **Yumitask**. Платформа-биржа: работодатели размещают задания, исполнители выполняют их за вознаграждение. Деньги — на внутреннем балансе, вывод и траты внутри платформы.

## Возможности (MVP)

- **Главный экран** — логотип, центральная кнопка «Биржа заданий», меню («Разместить задание», «Мой баланс», «Продвижение»), статистика платформы, плавающая круглая аватарка (фото из Telegram) в правом нижнем углу → в профиль.
- **Разместить задание** — форма: название, описание, категория (отзывы, соцсети, Telegram, подписки, лайки, просмотры, комментарии, другое), число исполнителей, оплата за одного, **авторасчёт бюджета** (N × цена), инструкция, типы подтверждения (скриншот, ссылка, текст, несколько, другое), срок. Перед публикацией показывается итоговая стоимость.
- **Найти задания (Биржа)** — карточки с категорией, оплатой, остатком мест, ~временем. Фильтры: по категории, сортировка «Новые / По оплате / Популярные». Открывается центральной кнопкой «Биржа» в таббаре или кнопкой «Биржа заданий» на главной.
- **Страница задания** — описание, вознаграждение, инструкция, требования, места, срок; кнопка «Взять задание»; после выполнения — «Отправить на проверку» с приложением подтверждения. Статусы: 🟡 на проверке, 🟢 выполнено, 🔴 отклонено (+ возможность повторить).
- **Внутренний кошелёк** — доступный баланс, история операций (+/−), кнопки «Вывести» и «Потратить баланс».
- **Тарифы работодателей** — Неделя 500 ₽ / Месяц 2 000 ₽ / 3 месяца 5 000 ₽ + баннер «Стать работодателем». Исполнителям оплата подписки работодателя не показывается.
- **Профиль и админ-панель** — статистика, мои задания, редактирование тарифов админом (цены меняются через админ-панель).

## Структура

```
index.html        — оболочка + подключение Telegram WebApp SDK (с офлайн-фолбэком)
css/style.css     — дизайн-система (тёмная/светлая темы, glassmorphism, safe-area)
js/store.js       — модель данных + демо-данные + localStorage
js/app.js         — ядро: Telegram WebApp, роутер, общие UI-хелперы
js/screens.js     — все экраны и бизнес-логика
server.js         — статический сервер (Node, без зависимостей)
bot.js            — Telegram-бот: /start и кнопка «Открыть Yumitask» (webhook)
```

## Запуск

**Вариант 1 — просто открыть (демо):** откройте `index.html` в браузере. Данные сохраняются в localStorage браузера.

**Вариант 2 — локальный сервер:**

```
node server.js
# → http://localhost:8081
```

## Подключение к Telegram

1. Создайте бота у [@BotFather](https://t.me/BotFather), получите токен.
2. У BotFather в настройках бота задайте **Menu Button → Web App** с URL вашего Mini App (нужен HTTPS-хостинг: GitHub Pages, Vercel, свой сервер и т.п.).
3. Укажите токен и домен и запустите бота:

```
set BOT_TOKEN=123456:ABC...
set MINI_APP_URL=https://ваш-домен.example/app
node bot.js
```

4. Для продакшена webhook: `set WEBHOOK_URL=https://домен/webhook` и зарегистрируйте
   `https://api.telegram.org/bot<TOKEN>/setWebhook?url=<WEBHOOK_URL>`.

> **Важно:** в `bot.js` замените `MINI_APP_URL` на реальный адрес. Без HTTPS Telegram Mini App не откроется.

## Деплой на GitHub + Vercel

Проект — чистый статический сайт (`vercel.json` уже в репозитории для корректной раздачи).

**1. GitHub**

1. Создайте новый репозиторий на GitHub (без README/.gitignore — они уже есть).
2. Загрузите код:
   ```
   git remote add origin https://github.com/<USER>/<REPO>.git
   git push -u origin master
   ```

**2. Vercel**

1. Зайдите на [vercel.com](https://vercel.com) → **Add New… → Project** → импортируйте репозиторий GitHub.
2. Vercel сам определит статический сайт (framework: **Other**).
3. Нажмите **Deploy** → получите URL вида `https://<repo>.vercel.app` (HTTPS).

**3. Telegram Mini App**

1. У [@BotFather](https://t.me/BotFather) в настройках бота: **Menu Button → Web App** → укажите `https://<repo>.vercel.app`.
2. В `bot.js` замените `MINI_APP_URL` на этот же URL, запустите бота (см. раздел выше) — или просто откройте ссылку приложения прямо из Telegram.

> **Примечание:** бот (`bot.js`, webhook на порту 8443) на бесплатном Vercel не работает — Vercel обслуживает только статику/серверные функции. Для продакшена бота нужен отдельный хостинг (VPS, Railway, Render и т.п.) или переделка в serverless-функцию Vercel. Само мини-приложение работает на Vercel без ограничений.

## Модель монетизации (v1)

Платное размещение через подписку работодателя. Без подписки — 1 активное задание. Цены и сроки легко менять в админ-панели (`js/screens.js`, раздел «Тарифы» — быстрая правка) или в `SUBSCRIPTIONS` в `js/store.js`.

## Дальнейшие шаги (вне MVP)

- Бэкенд с API (авторизация по `initData`, реальный баланс, проверка заданий работодателем).
- Платёжная интеграция для вывода (СБП, ЮMoney) и пополнения баланса.
